MiniPay — Procesador de pagos
Aplicación de consola escrita en Go
Proyecto para principiantes



Funciones que tendrá
1. Mostrar un menú interactivo en la consola.
2. Permitir pagar con tarjeta, PayPal o transferencia simulada.
3. Validar montos y rechazar entradas incorrectas.
4. Registrar los pagos en un historial usando un slice.
5. Mostrar el historial y el total procesado.
6. Manejar errores sin cerrar inesperadamente el programa.
7. Compilarlo como un ejecutable independiente.
