MiniPay — Payment Processor


Features

1. Display an interactive menu in the console.
2. Allow payments by credit/debit card, PayPal, or simulated bank transfer.
3. Validate payment amounts and reject invalid inputs.
4. Record payments in a transaction history using a slice.
5. Display the payment history and the total amount processed.
6. Handle errors without unexpectedly terminating the program.
7. Compile the application into a standalone executable.
